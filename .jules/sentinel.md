## 2024-05-24 - Security Headers for HTTP Server\n**Vulnerability:** The HTTP server (`apps/console/server.mjs`) used by ZeroSpend console lacked security headers such as `Content-Security-Policy`, `X-Content-Type-Options`, and `X-Frame-Options` on its endpoints and static file responses.\n**Learning:** When serving web applications, even local loopback-only ones, employing generic security headers provides an essential defense-in-depth layer to mitigate XSS (CSP), clickjacking (X-Frame-Options), and MIME-sniffing (X-Content-Type-Options).\n**Prevention:** Establish default safe HTTP headers dynamically in the core HTTP responder (e.g., `send` function) early in development to ensure all served resources inherit basic security policies.
