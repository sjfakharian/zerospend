# OpenRouter

ZeroSpend discovers explicit `:free` model IDs and requires zero prompt and completion prices in the current catalog. The provider-level `openrouter/free` random router is not used for task-specific ranking.

Create your own credential using [OpenRouter's official API authentication guide](https://openrouter.ai/docs/api/reference/authentication), then add it through the local Console Providers page. ZeroSpend never displays it again.
