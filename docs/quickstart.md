# Quickstart

Requirements: macOS, Node.js 22+, npm, and at least one supported provider account.

```bash
git clone https://github.com/sjfakharian/zerospend.git
cd zerospend
./install.sh
zerospend setup
npm run demo
```

The credential-free synthetic console opens at `http://127.0.0.1:20131`. Run `zerospend doctor` before enabling live routing.
